# 🤖 Bot 使い方ガイド

このBotは日常会話・雑務サポート・サーバー管理を1つにまとめたDiscord Botです。
Groq（Llama 3.3 70B）によるAI応答、モデレーション機能、リアクションロール、自動返信などを搭載しています。

## 権限について

- **オーナー専用**：Bot管理者（1名）のみ実行可能
- **サーバー管理者専用**：`管理者`権限を持つメンバーのみ実行可能（サーバー内限定）
- **利用許可ユーザー**：オーナーが `/add_user` で許可したユーザーのみ、コマンドを実行可能
- 利用が許可されていないユーザーがコマンドを使おうとすると、エラーメッセージが表示されます

## 💬 AI・便利機能

| コマンド | 説明 |
|---|---|
| `/help` | コマンド一覧を表示します |
| `/ai [質問内容]` | AIアシスタントに質問して回答をもらいます |
| `/summarize [URL]` | WebサイトやYouTube動画の内容をAIが要約します |
| `/make_schedule [予定データ]` | 予定やタスクを渡すと、1日の時間割を作成します |
| `/search [検索ワード]` | Google検索用のリンクを生成します |
| `/jst_time` | 現在の日本時間（JST）を表示します |

### AIチャットモード
特定のチャンネルをAI会話専用チャンネルに設定すると、コマンドなしで話しかけるだけでAIが返信します（利用許可ユーザーのみ）。

## 🎭 リアクションロール

| コマンド | 説明 |
|---|---|
| `/setup_reaction_role [メッセージID] [絵文字] [ロール]` | 指定したメッセージに絵文字でリアクションすると、自動でロールが付与されます。リアクションを外すとロールも外れます |

## ⚙️ サーバー管理（管理者・管理系権限が必要）

| コマンド | 説明 |
|---|---|
| `/set_log_channel [チャンネル]` | モデレーションログ（BAN・キック・メッセージ削除など）の送信先チャンネルを設定します。引数なしで実行すると解除されます |
| `/auto_reply [操作] [反応キーワード] [返信メッセージ]` | 特定キーワードにBotが自動返信する設定を追加・削除します |
| `/add_ng_words [NGワード] [処罰] [タイムアウト時間分]` | NGワードを登録します。処罰は「メッセージ削除のみ」または「タイムアウト」から選択 |
| `/remove_ng_words [削除するNGワード]` | 登録したNGワードを削除します |
| `/spam_detection [秒] [メッセージ数] [有効化]` | 指定した秒数内に指定回数以上投稿したユーザーを自動でタイムアウト＋メッセージ削除します |
| `/remove_invitation_link [有効にする]` |他のDiscordサーバーへの招待リンクを自動削除するかどうかを設定します |

## 🛡️ モデレーション（管理者専用・サーバー内限定）

| コマンド | 説明 |
|---|---|
| `/give_role [対象ユーザー] [付与する役職]` | ユーザーに役職を付与します |
| `/ban [対象ユーザー] [理由]` | ユーザーをBANします |
| `/kick [対象ユーザー] [理由]` | ユーザーをキックします |
| `/timeout [対象ユーザー] [時間分] [理由]` | ユーザーを指定時間タイムアウトします |
| `/purge [件数]` | チャンネル内のメッセージを最大100件まで一括削除します |
| `/lock_channel [状態]` | チャンネルをロック／ロック解除します（一般メンバーの閲覧・送信を制限） |

## 🌐 誰でも使えるコマンド

| コマンド | 説明 |
|---|---|
| `/purge_my_messages [件数]` | チャンネル内の自分のメッセージだけを一括削除します |

## 👑 オーナー専用コマンド

| コマンド | 説明 |
|---|---|
| `/add_user [ユーザー]` | Botの利用を許可するユーザーを追加します |
| `/sync` | スラッシュコマンドをDiscordに強制的に再同期します |
| `/shutdown` | Botを安全に停止します |

## 🔔 自動ログ通知

`/set_log_channel` で設定したチャンネルに、以下のイベントが自動で通知されます：

- メッセージの編集・削除
- メンバーのBAN・キック・脱退
- 手動／自動タイムアウトの付与
- NGワード検知・招待リンク検知・スパム検知によるモデレーション実行

## 🚫 自動モデレーション

サーバー設定で有効化しておくと、以下を自動検知して対応します：

- **NGワード**：登録した単語を含むメッセージを削除（＋タイムアウト設定も可能）
- **招待リンク**：他サーバーへの招待URLを自動削除
- **スパム連投**：短時間に大量投稿したユーザーを自動タイムアウト
